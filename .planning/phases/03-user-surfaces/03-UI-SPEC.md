## Spacing Scale

Declared values (multiples of 4, mapped to Tailwind v4 defaults):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (`gap-1`, `p-1`) | Icon gaps, chip inner padding, badge padding |
| sm | 8px (`gap-2`, `p-2`) | Compact element spacing, card internal row gaps |
| md | 16px (`gap-4`, `p-4`) | Default element spacing, card padding, form field spacing |
| lg | 24px (`gap-6`, `p-6`) | Section padding, card grid gap |
| xl | 32px (`gap-8`, `p-8`) | Layout gaps, page horizontal padding on desktop |
| 2xl | 48px (`gap-12`) | Major section breaks (e.g., between status card and chat thread) |
| 3xl | 64px (`gap-16`) | Page-level top/bottom padding (chatbot page only) |

**Exceptions:**
- Touch target minimum: 44px height on all action buttons (`Llamar`, `Marcar presentado`, `Reabrir`, quick-reply chips, chat submit). Use `min-h-[44px]` override where Tailwind default is smaller.
- Connection dot indicator: 10px diameter (`w-2.5 h-2.5`), not on the 4px grid — smallest viable visual affordance.
- Left-border color band on queue cards: 4px (`border-l-4`) — on grid.

## Typography

All sizes reference Tailwind v4 default scale (which maps to `rem` units). Explicit px equivalents listed for the checker.

| Role | Size | Weight | Line Height | Tailwind class | Usage |
|------|------|--------|-------------|----------------|-------|
| Body | 16px (`text-base`) | 400 (regular) | 1.5 | `text-base font-normal leading-normal` | Chat messages, card body text, form inputs, history table rows |
| Label | 14px (`text-sm`) | 500 (medium) | 1.4 | `text-sm font-medium leading-snug` | Card field labels, badge text, status pills, connection dot label, ETA/position metadata |
| Heading | 20px (`text-xl`) | 600 (semibold) | 1.2 | `text-xl font-semibold leading-tight` | Page H1 "Cola de Espera", panel section titles, card name field |
| Display | 28px (`text-3xl`) | 700 (bold) | 1.1 | `text-3xl font-bold leading-none` | Push banner "TU MESA ESTÁ LISTA" — uppercase, single-line urgency copy only |

**Weights in use:** regular (400) + medium (500) + semibold (600) + bold (700).
**Justification for 4 weights:** bold is reserved exclusively for the "TU MESA ESTÁ LISTA" banner — the single highest-urgency message in the entire product. Every other element uses regular/medium/semibold. No weight is shared across contexts; each weight signals a distinct level of priority.

**Font stack:** Geist Sans via `--font-sans` CSS variable (already set in `app/globals.css`). No additional font imports needed.

## Color

Color tokens already declared in `app/globals.css` as OKLCH CSS variables, consumed via Tailwind `bg-background`, `text-foreground`, `bg-card`, etc.

### Base semantic split (60/30/10)

| Role | Light mode value | Dark mode value | Usage |
|------|-----------------|-----------------|-------|
| Dominant (60%) | `--background: oklch(1 0 0)` (white) | `oklch(0.145 0 0)` (near-black) | Page background, chat thread area, full-page chatbot surface |
| Secondary (30%) | `--card: oklch(1 0 0)` / `--muted: oklch(0.97 0 0)` | `--card: oklch(0.205 0 0)` | Queue cards, status card, history table rows, nav bar background, composer area |
| Accent (10%) | `--primary: oklch(0.205 0 0)` (near-black) | `--primary: oklch(0.922 0 0)` (near-white) | Primary CTA buttons only (see reserved list below) |
| Destructive | `--destructive: oklch(0.577 0.245 27.325)` (red) | `oklch(0.704 0.191 22.216)` | "Marcar no-show (manual)" button only — if exposed; no-show is automatic in Phase 3, but error toasts use this color |

**Accent reserved for:**
1. Chat submit button ("Enviar") — `bg-primary text-primary-foreground`
2. "Llamar" action button on queue cards — `bg-primary text-primary-foreground`
3. "Marcar presentado" action button — `bg-primary text-primary-foreground`
4. "TU MESA ESTÁ LISTA" banner background (derived from party-size Edge Config color, NOT `--primary` — see party-size palette below)

**Destructive reserved for:**
1. Error toast text via shadcn `Sonner` (e.g., `409 RESERVATION_ALREADY_CLOSED`)
2. SSE reconnect-failure banner text ("Sin conexión en vivo. Refrescá la página.")

**Not accent:** tab navigation links, secondary info text, skeleton placeholders, heartbeat/connection dot (uses semantic green/yellow/red, see below).

### Party-size color palette (Edge Config `colors_by_party_size`)

Seeded in Edge Config as `{"1-2":"#A8E6CF","3-4":"#FFD3B6","5-6":"#FFAAA5","7+":"#D5AAFF"}`.

These pastel hex values are used ONLY for:
- `border-l-4` left-border on queue cards (CSS inline style: `style={{ borderLeftColor: partyColor }}`)
- Party-size badge background (small chip in card top-right: `style={{ backgroundColor: partyColor }}`)
- Push banner background when `status === "called"` (the banner adopts the diner's party-size color for visual urgency)

Card background stays `bg-card` (white/dark slate) — party color is never applied to full card background (readability constraint, documented in CONTEXT.md D-14).

## Surface Specifications

### Surface 1: Diner Chatbot (`/`)

**Layout:** Full-page, single-column, `max-w-md mx-auto`, mobile-first. No nav. No sidebar.

**Structure (top to bottom):**
1. **Page header** — `h-12 flex items-center px-4 border-b`. Contains: H1 "Cola de Espera" (`text-xl font-semibold`) + 1-line tagline "Anotate en la cola del restaurante" (`text-sm text-muted-foreground`). Visible always. No nav links.
2. **Status card** — visible only when localStorage has a valid active session token AND `/api/me` returns `status: waiting | called`. `bg-muted rounded-lg mx-4 mt-4 p-4`. Shows: "TU RESERVA: Posición #N · ETA X min · estado". Hidden for new diners. Source: CONTEXT.md D-09.
3. **Push banner** — sticky, `position: sticky top-0 z-50`, hidden by default. Transitions between states: hidden → "TU MESA ESTÁ LISTA" → "¿Estás en camino?" → seated/closed. Background from party-size Edge Config color. `aria-live="assertive"` for screen readers. Full behavior spec in CONTEXT.md D-05.
4. **Quick-reply chips** — horizontal scroll row directly below push banner, visible only during `called` and `followup_proactive` states. Pills using `Button variant="outline" size="sm" rounded-full`. Source: CONTEXT.md D-06.
5. **Chat thread** — scrollable area between header and composer. `flex-1 overflow-y-auto px-4 py-2`. Chat bubbles: diner messages right-aligned `bg-primary text-primary-foreground rounded-2xl rounded-br-sm`; assistant messages left-aligned `bg-muted text-foreground rounded-2xl rounded-bl-sm`. Body size (16px / weight 400 / 1.5 line-height).
6. **Composer** — sticky bottom, `sticky bottom-0 border-t bg-background px-4 py-3 flex gap-2`. Input (`flex-1`) + Enviar button (`min-h-[44px]`). Disabled while `status !== "ready"` from `useChat`.

**Error state:** Network-level error banner above the composer (NOT in chat thread): `bg-destructive/10 text-destructive text-sm px-4 py-2 rounded` — "No pude contactar al servidor. Intentá de nuevo en un momento." Dismissable.

**Confirmation badge:** Rendered inside assistant chat bubble ONLY when `tool-result part` contains `ok === true && data.reservation_id`. Markup: `<span class="inline-flex items-center gap-1 bg-green-50 text-green-700 text-xs font-medium px-2 py-0.5 rounded-full border border-green-200">✓ Reserva #{id.slice(0,8)}</span>`. Never rendered from LLM text alone. Source: CONTEXT.md D-03, Pitfall #16.

### Surface 2: Maître Panel (`/queue`)

**Layout:** Mobile-first, `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-3 p-4`. Auth-protected.

**Nav bar** (`h-12 border-b px-4 flex items-center justify-between`):
- Left: "Panel de Maître" (`text-base font-semibold`)
- Center: `Activas | Historial` tab links (shadcn `Tabs` or plain nav with `font-medium text-sm` active / `text-muted-foreground` inactive)
- Right: Connection dot (10px circle) + "en vivo" / "reconectando" / "sin conexión" label (`text-xs text-muted-foreground`)

**Queue card anatomy** (`rounded-lg border bg-card shadow-sm border-l-4 p-4 flex flex-col gap-2`):
- `border-l-4` color = `colors_by_party_size` inline style
- **Top row:** party-size badge (color chip, `text-xs font-medium px-1.5 py-0.5 rounded`) + name (`text-base font-semibold truncate flex-1`) + extension badge ("extendido ×N" in `bg-orange-100 text-orange-700 text-xs rounded-full px-2`) if `extension_count > 0`
- **Middle row:** "Esperando hace X min" (`text-sm text-muted-foreground`) + "ETA Y min" (`text-sm`) + status pill (see color table above)
- **Bottom row:** action buttons, `flex gap-2 mt-2`. Button rules:
  - `status === "waiting"`: `[Llamar]` button (`Button variant="default" size="sm" min-h-[44px]`). "Marcar presentado" is absent (not just disabled — do not render).
  - `status === "called"`: `[Marcar presentado]` button (`Button variant="default" size="sm" min-h-[44px]`). "Llamar" is absent.
  - Both actions: loading spinner replaces button text during POST request. Button re-enables on SSE state transition (not on HTTP 200 — wait for SSE confirmation per D-15).

**Loading state:** 3 skeleton cards. `Skeleton` from shadcn, `h-24 rounded-lg`.

**Empty state:** Full-width centered text block — Heading: "Sin reservas activas" (`text-heading font-semibold`). Body: "Cuando alguien se anote, va a aparecer acá." (`text-sm text-muted-foreground`). + small "Última actualización: HH:MM:SS" below (`text-xs text-muted-foreground`).

**SSE error state (≥3 failed reconnects):** Red banner at top of card grid — "Sin conexión en vivo. Refrescá la página." (`bg-red-50 border border-red-200 text-red-700 text-sm rounded px-4 py-2`). Last-known snapshot remains visible; do NOT blank the grid.

**Action error toast:** shadcn `Sonner`, position `bottom-right`. Shows Spanish error message from API response `error.message`. Auto-dismiss after 5s. Button that triggered the error auto-disables (SSE will also arrive to sync state).

### Surface 3: Maître History (`/queue/history`)

**Layout:** Full-width table, desktop-first (dense audit data). Auth-protected.

**Table columns:** Hora llegada | Nombre | Tamaño | Estado | Duración en cola | Acción

**Table styling:** `w-full text-sm border-collapse`. Header row: `bg-muted text-muted-foreground font-medium`. Body rows: alternating `bg-background` / `bg-muted/30`. Row hover: `hover:bg-muted/50`.

**Status badges in table:** Same status pill system as queue cards (see color table above).

**Reabrir action (no_show rows only):** `Button variant="outline" size="sm"` labeled "Reabrir". Triggers shadcn `AlertDialog` — title: "¿Confirmás reabrir?" — body: "Se va a crear una nueva entrada en la cola activa." — actions: `[Cancelar]` (ghost) + `[Confirmar]` (default). On confirm → POST to `/api/queue/[id]/reopen`.

**Empty state:** "No hay reservas cerradas hoy." (`text-sm text-muted-foreground text-center py-8`).

**Loading state:** 4 skeleton rows (each `h-8`).

**Polling:** Every 30 seconds client-side. No SSE on this page.

## Interaction Contracts

### Chatbot (`/`) — state machine

| From state | Trigger | To state | UI change |
|------------|---------|----------|-----------|
| no-session | Page mount, localStorage empty | welcome | Show greeting bubble, hide status card, hide banner |
| no-session | Page mount, localStorage has token, `/api/me` returns active | hydrated | Show status card, open SSE, hide banner initially |
| hydrated | SSE event `called` | push-called | Show "TU MESA ESTÁ LISTA" banner (party-size color bg) |
| push-called | SSE event `followup_proactive` (1 min after called) | push-followup | Banner mutates to "¿Estás en camino?" + chips |
| push-followup | Chip "Pedir más tiempo" clicked | chat-sending | `sendMessage({text: "dame 5 más"})` — chip posts to chat |
| push-followup | Chip "Cancelar" clicked | chat-sending | `sendMessage({text: "no voy a ir"})` — chip posts to chat |
| any | SSE event `seated` | closed-seated | Banner → "Bienvenido. Disfrutá la cena." + clear localStorage on "Salir" click |
| any | SSE event `no_show` or `cancelled` | closed-end | Banner → empathic copy + "Anotarme de nuevo" clears localStorage |
| chat-sending | `status !== "ready"` | sending | Composer input disabled, button shows spinner |
| chat-sending | `status === "ready"` | idle | Composer re-enabled |

### Queue panel (`/queue`) — action flow

| Trigger | Immediate UI | After SSE confirmation |
|---------|-------------|----------------------|
| Llamar clicked | Button → loading spinner, disabled | Card status pill → `called` (amber), Llamar removed, Marcar presentado appears |
| Marcar presentado clicked | Button → loading spinner, disabled | Card disappears from grid (SSE: status no longer `waiting` or `called`) |
| API 404/409 response | Error toast (Sonner), button re-enables | SSE update syncs state anyway |
| SSE new reservation | New card slides/fades into grid | — |
| SSE reconnect | Snapshot-replay fills any gap automatically | Connection dot returns to green |

### Reopen flow (`/queue/history`)

| Trigger | UI |
|---------|-----|
| Reabrir button clicked | AlertDialog opens |
| Dialog "Cancelar" | Dialog closes, no change |
| Dialog "Confirmar" | Dialog closes, button → loading, POST `/api/queue/[id]/reopen` |
| POST 200 | Toast "Reserva reabierta. Aparece en la cola activa." (Sonner, green) |
| POST 4xx | Toast with error message (Sonner, destructive) |

## Accessibility Contract

| Requirement | Implementation |
|-------------|----------------|
| Push banner screen reader | `aria-live="assertive"` on banner container; changes announced immediately |
| Action buttons | `aria-label` includes reservation name (e.g., `aria-label="Llamar a Juan (4 personas)"`) |
| Status pills | `role="status"` on each pill; color not sole differentiator — text label present |
| Connection dot | `title` attribute with full status text (e.g., `title="SSE conectado"`) |
| Composer input | `aria-label="Mensaje para el chatbot"`, `aria-disabled` when sending |
| Confirmation dialog | shadcn AlertDialog uses `role="alertdialog"` and manages focus trap automatically |
| Minimum tap target | 44px minimum height on all interactive elements |
| Color contrast | shadcn base-nova neutral tokens meet WCAG AA at default; party-size pastels (light fill) paired with dark text — verify `FFAAA5` (#5-6 red) against dark text in dev |
